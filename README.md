# App1
Første appen - lekeprosjekt med claude

A small todo app built with Vite, React and TypeScript. Todos are saved in the browser (localStorage).

## Features
- Add, check off, and delete todos
- Double-click a todo to edit it (Enter saves, Escape cancels)
- Filter by All / Active / Done, and clear finished todos

## Getting started
```sh
npm install
npm run dev      # start the dev server
npm test         # run the unit tests
npm run build    # type-check and build for production
npm run lint     # lint with oxlint
```
